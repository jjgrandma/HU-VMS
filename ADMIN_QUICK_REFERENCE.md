# Admin Quick Reference Card

## 🔐 Password Reset & Support Management

### Access Path
```
Admin Login → Sidebar → "Password & Support"
```

---

## 📋 Two Main Tabs

### 1️⃣ Password Reset Requests
**What you see:** Users who requested password resets

**Actions:**
- 🔗 **Send Reset Link** - Generate & send URL to user
- 🔄 **Reset Password** - Set temporary password directly

### 2️⃣ Support Messages  
**What you see:** Users who contacted support

**Actions:**
- 💬 **Send Response** - Reply to user's message
- 🔗 **Send Reset Link** - Quick password reset option

---

## 🚀 Quick Actions Guide

### When User Forgot Password:
1. Go to "Password Reset Requests" tab
2. Find the user
3. Click "Send Reset Link"
4. Copy URL from console
5. Send to user via email/phone

### When User Contacts Support:
1. Go to "Support Messages" tab
2. Click on the message
3. Read user's issue
4. Type your response
5. Click "Send Response"

---

## 💡 Pro Tips

✅ Check token expiration times  
✅ Use "Reset Password" for urgent cases  
✅ Keep responses professional and clear  
✅ Mark resolved issues for tracking  
✅ Use refresh button to see new requests  

---

## 📞 Common Scenarios

| User Issue | Admin Action | Result |
|------------|--------------|--------|
| Forgot password | Send Reset Link | User gets URL to reset |
| Account locked | Reset Password | User gets temp password |
| Can't login | Check Support Messages | Respond with solution |
| Need help | View message details | Send instructions |

---

## 🔒 Security Notes

- All actions require admin authentication
- Reset links expire in 1 hour
- Passwords are securely hashed
- Only ADMIN role has access
